# Vestaland

نسخه اولیه PWA وستالند؛ یک اپ فارسی RTL با تمرکز روی کامیونیتی دخترونه، ابزارهای شخصی و بازار.

## MVP فعلی

- onboarding با تست ۴ سوالی «اعتبارسنجی دخترونه» به‌عنوان سرگرمی
- انتخاب ۷ روز آزمایشی یا اشتراک ۱، ۳ و ۶ ماهه
- دورهمی: درددل، غیبت، مشورت، چالش روزانه و پز
- قوانین تعاملی متفاوت برای هر نوع پست
- ثبت پست و واکنش‌ها با ذخیره محلی در مرورگر
- «خودم»: ثبت حال روزانه، گیاه واکنشی و تقویم چرخه
- بازار با دسته‌بندی، فیلتر وستا/کیوتلا، جستجو و سبد آزمایشی
- PWA و Service Worker
- deploy خودکار روی `vestaland.smarbiz.sbs`

## معماری این مرحله

این نسخه عمداً frontend-first است تا UX و product flow روی موبایل تست شود. وضعیت دمو در `localStorage` ذخیره می‌شود. مرحله بعدی اتصال همین UI به API و دیتابیس واقعی، auth، moderation، media uploads، push notification، subscription billing و اتصال فروشگاه‌هاست.

## Deploy

هر push روی `main` توسط GitHub Actions با سکرت‌های `HOST` و `PASS` روی سرور منتشر می‌شود. اگر `HOST` شامل `user@host` نباشد، workflow از `root@HOST` استفاده می‌کند.
