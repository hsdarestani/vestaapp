# Vestaland — Personal wardrobe & beauty (2026 overhaul)

The community-first experience is disabled in the new UI. Vestaland is now a Persian RTL, mobile-first wardrobe and beauty organizer with pastel pink puffy/soft-3D design.

## Features in this iteration

- Digital wardrobe: photograph garments, categorize, select colors, save and delete items.
- Personal beauty shelf: cosmetics/skincare inventory, opening date, labeled PAO (period after opening), morning/night routines and approximate date warnings.
- Outfit ideas generated by **deterministic category/color matching**, **not generative AI**. No virtual try-on claim.
- Live Vesta and Cutella WooCommerce Store API product discovery through the bundled read-only market proxy. Product links open the actual merchant checkout; no duplicate payments.
- Browser/WebView IndexedDB stores personal items and compressed images locally on each device, with JSON export/import. No cloud sync, authentication, or automatic image recognition yet.
- Existing community data/services are left intact for historical preservation but no community posts, plans, feeds, or notifications are exposed by the redesigned app.

## Privacy and migrations

Changing the app from `vestaland.smarbiz.sbs` to `app.vesta-cosmetics.ir` changes the WebView storage origin. Old local-only browser data does not automatically migrate. Do not delete legacy backend data or the old domain until a safe user-data export plan exists.

## Deployment safety

**DO NOT RUN** the legacy `scripts/deploy-production.sh` on the Vesta/Cutella server. It installs and rewrites host Nginx and removes the default site; it was written for a different VPS.

See `deploy/README.md` for isolated Docker services, origin certificate requirements, new subdomain DNS, and safe rollout. Publishing to Bazaar requires building/signing with the original keystore. Existing Android application ID `ir.vestaland.app` is preserved.
